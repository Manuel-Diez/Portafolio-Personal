# Portafolio-Personal

Portafolio de proyectos propios, organizado por madurez en vez de por
lenguaje: qué tan sustancial es la idea que hay detrás, no con qué se
construyó.

## `proyectos/` — trabajos sustanciales

Sistemas con lógica de negocio real, aunque algunos sigan en desarrollo.

| Carpeta | Qué es |
|---|---|
| [`posada/`](proyectos/posada) | Sistema de reservas de hotel — Spring Boot + React, JWT |
| [`clinica-san-rafael/`](proyectos/clinica-san-rafael) | Gestión de pacientes, médicos e ingresos — Spring Boot + jQuery |
| [`estante/`](proyectos/estante) | Préstamos y multas de una biblioteca — Spring Boot |
| [`talonario/`](proyectos/talonario) | Motor de facturación (clientes, productos, IVA, stock), con login JWT real — Spring Boot |

## `ejercicios/` — piezas de aprendizaje

Más pequeños y acotados; cada uno demuestra un concepto puntual.

| Carpeta | Qué es |
|---|---|
| [`jornalia/`](ejercicios/jornalia) | Cálculo de salario prorrateado — C#, herencia/interfaces/SOLID/async |
| [`centinela/`](ejercicios/centinela) | Módulo de control de acceso, con login y JWT reales — ASP.NET Core, EF Core + Dapper |
| [`mostrador/`](ejercicios/mostrador) | Punto de venta con cálculo automático de totales — Spring Boot |
| [`vestier/`](ejercicios/vestier) | Ejemplos de POO y los 5 principios SOLID sobre una tienda de ropa — C# |

Cada carpeta tiene su propio README contando de qué se trata y qué le
faltaba cuando le puse la mano.
